# Обсуждение Winter Quest

Сюда попадают интересные автору игры обсуждения. Сырой материал, черновик.

## Начало

> 🗣️️ Я с детства мечтал сделать атмосферный point-n-click детский квест про зиму, причём на html для браузера! Посоветуй, что туда добавить? Ну, там должен будет быть посёлок, хрустящий снег, следы на снегу, белочка (которую можно покормить орешками), возможность разжечь костёр, домик с камином, возможность построить снеговика.

🤖 DeepSeek, 2026.09.15:

### Белочка

- Кормление орешками — не просто «дал → получил спасибо». Сделай прогрессию доверия: первый раз убегает, второй — берёт с руки, третий — приводит к тайнику.
- Белка может стать проводником: показывает, где спрятано что-то, если её покормить.
Орешки можно найти, а не просто получить: под дубом, в дупле, в кармане дедушки.

### Домик с камином

- Камин — центр «домашнего» уровня. Здесь можно пить чай, читать книгу (лор мира!).
- Камин может гаснуть, и его надо поддерживать — мягкая, не стрессовая механика для детей.

### Снеговик

- Постройка снеговика — идеальная составная загадка: слепить 3 кома (нужен снег определённой «липкости»), найти морковку, угольки, шарф, ведро.

### Что добавить для атмосферы и глубины

Мир и жители

- Посёлок: 3–5 домиков, каждый со своим характером (бабушка с пирожками, дед-рыбак, кузнец, библиотекарь).
- Зимние звуки: скрип снега, вой ветра, треск поленьев, уханье совы, звон колокольчиков. Звук — 50% атмосферы.
- Время суток: утро → день → сумерки → ночь. Ночью — другие события (звёзды, северное сияние, свет в окнах).
- Погода: снегопад, метель (ограничивает видимость — головоломка!), оттепель (снеговик тает!).

### Механики, которые работают на атмосферу

- Шкала тепла/холода — мягкая, не наказывающая. Замёрз — иди к костру или домой.
- Фотоаппарат — фиксировать красивые моменты, потом показывать NPC.
- Дневник героя — автоматически записывает, что узнал, куда идти (спасает от тупика).

### Техническая реализация на HTML

Стек (простой и рабочий)

- HTML5 Canvas или DOM + CSS для сцен. Для point-n-click DOM удобнее: хитбоксы — это `<div>` с position: absolute.
- JavaScript — логика. Можно без фреймворков, но удобно взять Phaser 3 (игровой движок) или PixiJS (рендер).
- Ассеты: SVG для объектов (масштабируется, легко анимировать), PNG/WebP для фонов.
- Звук: Howler.js — простая библиотека для звуков и музыки.
- Хранение прогресса: localStorage — сохранение без сервера.

### Советы по атмосфере

- Цветовая палитра: холодные синие/голубые для улицы, тёплые оранжевые/жёлтые для интерьеров. Контраст — сердце атмосферы.
- Тишина — тоже звук. Не заливай всё музыкой. Пусть будет только ветер и скрип снега — это погружает.
- Мелкие детали: дым из труб, пар от дыхания, иней на окнах, сосульки, следы птиц на снегу.
- Мягкие переходы между сценами: fade to black, а не резкий скачок.
- Реакции на всё. Даже если предмет не нужен — герой должен что-то сказать. «Снег. Холодный. Брр.»
- Никакого стресса. Детский квест — это про исследование, а не про «успей за 30 секунд».
- Финальная сцена должна быть тёплой. Костёр, камин, чай, все друзья рядом — эмоциональная награда.
